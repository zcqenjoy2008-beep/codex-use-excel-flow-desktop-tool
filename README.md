# 成交流水 Excel 桌面工具

## 项目作用
本项目将原始 Python 脚本改造为 **Windows 桌面 GUI 应用**，用于批量读取两类成交 Excel 数据、执行业务清洗规则，并将结果写入指定模板文件。

## 已修复的原脚本问题
1. **写入数据源错误**：`质押式回购` 原脚本误写入 `merged_data1`，现修复为写入协议回购数据（`merged_data2`）。
2. **保存方式不规范**：原脚本通过 `pd.ExcelWriter(...).save()` + 手动 `writer.book`，改为 `openpyxl.load_workbook` 后直接 `book.save()`，避免兼容问题。
3. **缺列时直接崩溃**：原脚本使用 `sheet_df[list(columns)]` 会在缺列时报错，现改为逐 sheet 检查缺列并记录日志跳过。
4. **空文件夹/空sheet处理不足**：现支持空文件夹、空 sheet，最终写空结果且给出日志。
5. **缺少清晰报错**：针对路径不存在、缺工作表、读取失败、保存失败等增加明确错误信息。

## 技术方案
- GUI：`Tkinter`（Python 标准库，依赖少，易打包）
- 数据处理：`pandas + openpyxl`
- 打包：`PyInstaller`

```bash

```

## 使用步骤
1. 选择 **成交信息 pb 文件夹**。
2. 选择 **协议回购成交信息 pb 文件夹**。
3. 选择 **Excel 模板文件**（建议保留完整模板格式）。
4. 选择 **输出文件保存路径**。
5. 点击 **开始处理**。
6. 在日志区查看进度、跳过项、完成情况；结束后弹窗提示成功/失败。

## 业务规则说明（保持原逻辑）
### 数据1（成交信息 pb）
- 全表替换：`固定收益平台 -> 上交所固定收益平台`
- 条件修正业务分类：
  - 证券名称含 `E` 且交易市场为 `深交所A` -> `固收收益平台`
  - 交易市场为 `深交所A` 且证券类别不等于 `可转债` -> `固收收益平台`
- 移除中间字段：`证券名称`、`证券类别`

### 数据2（协议回购成交信息 pb）
- 替换：
  - `正回购续做 -> 正回购`
  - `逆回购续做 -> 逆回购`

### 模板写入
- `现券买卖`：从第4行开始写入数据1
- `质押式回购`：从第4行开始写入数据2
- `协议回购`：从第4行写入数据2到 A,B,C,D,E,F,G,H,I,J,L 列

## Windows 打包（exe）
### 推荐命令
在项目根目录执行：
```bash
pyinstaller --noconfirm --clean --onefile --windowed --name excel-flow-desktop main.py
```

### 输出位置
- 生成的 exe 位于：`dist/excel-flow-desktop.exe`

### 用户运行方式
- 将 `dist/excel-flow-desktop.exe` 双击运行即可。
- 首次运行若被系统拦截，请在 Windows 安全提示中选择“仍要运行”（企业环境按内网规范处理）。

## 常见报错说明
1. **模板缺少工作表**：模板中必须包含 `现券买卖`、`质押式回购`、`协议回购`。
2. **路径不存在**：输入文件夹或模板路径失效。
3. **缺少关键列**：某些 sheet 缺列会被跳过，并在日志区提示缺失列。
4. **文件占用导致保存失败**：请关闭正在打开的输出文件后重试。
